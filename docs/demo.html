junit2context · open source · MIT

Less test-report noise.
More useful debugging context.

Turn existing JUnit XML reports into a compact brief for Claude Code, Codex, or your own debugging session. Runs locally. No API key.

Start with the reports your tests already produce

These bundled, synthetic pytest-style and Vitest-style fixtures contain passing tests, skipped tests, captured output, and three failed tests. The credential below is an invented demo value.

One local command

junit2context examples/pytest.xml examples/vitest.xml

Reads reports, keeps failures and errors, deduplicates repeated failures, and masks common credential patterns. Long traces keep their beginning and end.

Python 3.10+Zero runtime dependenciesMarkdown + JSON

The converter does not run tests, contact a model, or modify your code.
